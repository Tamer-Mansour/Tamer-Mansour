### 🤖 PDF AI – RAG-Powered Document Query App
> **Tech:** Flask · LangChain · ChromaDB · HuggingFace · Google Gemini · LM Studio · Python

Built a full-stack AI application using **Retrieval-Augmented Generation (RAG)** for interactive, context-aware querying of PDF documents in **Arabic and English**.
- Custom Regex-based normalization + semantic chunking via `RecursiveCharacterTextSplitter`
- HuggingFace multilingual embeddings + local ChromaDB vector store
- Flexible LLM abstraction: cloud (Google Gemini) or local (LM Studio)
- Real-time token streaming + network diagnostics
